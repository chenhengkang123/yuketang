# 雨课堂视频播完自动下一单元（yuketang-auto-next）

[雨课堂](https://www.yuketang.cn)学习空间（`/ai-workspace/`）的视频**播完后自动点击「下一单元」**，实现连续播放。遇到作业等非视频单元自动跳过，继续播放下一个视频（可配置为停止等待）。

只提供 Chrome 扩展。

> 配合 [yuketang-no-pause](../yuketang-no-pause-extension)（防暂停）使用效果更佳：防暂停保证切标签页/最小化后视频不停播，本脚本保证播完自动翻页，两者互不冲突。

## 原理

学习空间是 SPA（切换单元不刷新页面），脚本以 1 秒轮询驱动：

1. **辨别单元类型**：看 URL —— 含 `/video/` 是视频单元；作业是 `/exercise/`（不含 `video`）。
2. **视频单元**：轮询 `<video>` 的 `ended`，外加「距结尾 ≤5 秒」兜底；播完 1.5 秒后点击页面右上角的「下一单元」箭头（`.unit-arrow.arrow-reverse`，同款的 `<` 不带 `arrow-reverse`）。找不到箭头时兜底点击侧边栏目录中当前高亮项（`.leaf-item.is-active`）的下一个 `.leaf-item`。
3. **非视频单元**：默认自动跳过，继续找下一个视频（最多连跳 10 个防失控）；只有脚本自己点进来的作业页才会被跳过（你手动打开的作业页绝不会被自动跳过）。
4. **连播续播**：进入新视频单元后若未自动播放，自动补 `play()`；点击后 15 秒 URL 未变化视为已是最后一个单元，停止。

所有动作都会在控制台输出 `[雨课堂自动连播]` 日志，并在页面右上角弹 4 秒角标提示。

学习空间页面左下角有两个按钮，扩展保持启用即可随时开关：

- **连播开 / 连播关**：关掉后播完停在当前单元。选择记在 `localStorage`（`yuketang-auto-next`），刷新和以后打开都保留。快捷键 `Alt+N`。
- **本集后停**：当前视频播完后不翻页，只生效一次。记在 `sessionStorage`，关掉这个标签页就清除。

全屏时若全屏元素不是 `<video>` 本身，按钮会跟进全屏层；全屏的是视频元素时用 `Alt+N`。

## 安装

1. 下载本仓库（Code → Download ZIP 后解压，或 `git clone`）
2. 打开 Chrome / Edge，地址栏输入 `chrome://extensions`
3. 打开右上角「开发者模式」
4. 点击「加载已解压的扩展程序」，选择 `yuketang-auto-next-extension` 文件夹
5. **刷新**已打开的雨课堂学习空间页面（之后新开的页面自动生效）

> 扩展按文件夹路径引用，加载后不要移动/删除该文件夹。改完 `inject.js` 后在 `chrome://extensions` 点一次该扩展的刷新，再刷新雨课堂页面。

## 配置

行为开关在页面上。下面这些仍在 `inject.js` 顶部：

| 配置 | 默认 | 说明 |
|---|---|---|
| `SKIP_NON_VIDEO` | `true` | `true` 时遇到作业等非视频单元自动跳过（最多连跳 10 个防失控）；`false` 时停下等人工 |
| `NEXT_DELAY` | `1500` | 播完后延迟多久点下一单元(ms)，给完成度上报留时间 |
| `END_GRACE` | `5` | 距结尾多少秒视为播完（`ended` 事件的兜底；雨课堂有时差几秒就停住） |
| `AUTO_PLAY` | `true` | 连播进入的新视频未自动播放时补 `play()` |
| `DEBUG` | `true` | 控制台日志开关 |

## 实测验证

在雨课堂真实学习空间（`yuketang.cn/ai-workspace/lms-graph/...`）验证：

| 场景 | 结果 |
|---|---|
| 视频播完（已完成单元） | 自动点「下一单元」，1.5s 内跳转 |
| 下一单元是作业（`/exercise/`） | 自动跳过，继续播放下一个视频 |
| 未完成单元拖拽到结尾骗翻页 | 无效 —— 雨课堂会把进度弹回已看位置 |

## 说明

- 雨课堂有防拖进度机制：未看完的部分无法拖动快进，所以本脚本只在视频**真实播完**时翻页，不能用来秒刷，正常倍速挂机即可。
- 脚本仅做前端页面自动化，学习进度由雨课堂心跳正常上报，请按课程要求合理使用，仅供学习研究。
- 若雨课堂未来改版导致失效，欢迎提 Issue。
